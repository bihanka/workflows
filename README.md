# workflows

Git Flow y GitHub Actions: ramas main, dev y build.

## Flujo

- `main`: rama protegida. Solo recibe cambios por Pull Request.
- `dev`: rama de integracion.
- `build`: la crea GitHub Actions con el resultado de `npm run build`.

El detalle del flujo, los Pull Requests y las capturas estan en [FLUJO.md](FLUJO.md) y en la carpeta `evidencias/`.
